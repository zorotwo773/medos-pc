MEDOS 1.1.5 RELEASE CANDIDATE

Start MedOS

Keep the complete folder together. Windows and Mac use bundled runtimes; Linux installs native core dependencies on first setup. Read the current guide before applying an update.

Windows

  1. Extract the entire release to its permanent folder.
  2. Open START HERE - WINDOWS.cmd.
  3. Click Start MedOS and wait for local-service health.

Activation creates one MedOS shortcut and no second copy of medical data. Keep an external SSD connected.

Mac

  1. Open MedOS.app inside the complete extracted folder.
  2. Keep the app beside the rest of MedOS. Use an alias or Dock item if desired.
  3. If a trusted first open is blocked, use System Settings → Privacy & Security → Open Anyway after attempting to open it.

If the app reports a missing drive, reconnect it. If macOS relocates the app or the launcher reports missing files, open MedOS.command from the complete folder as directed. Apple Silicon and Intel runtimes are bundled; native Mac acceptance remains pending.

Linux

Python 3.11–3.14 (3.12 recommended), Node.js 22 LTS version 22.13+ recommended (minimum 20.9), and npm. Prefer a native Linux filesystem.

bash "START HERE - LINUX.sh"

Use a dedicated complete Linux copy; setup replaces frontend dependencies with native Linux packages. Keep a separate copy for Windows/Mac. First setup needs network for the core Python requirements, verified linux/requirements-lock.txt, and npm ci. Later core use is offline; AI/ML is optional. Leave the terminal open and stop with Ctrl+C. Logs: .medos-linux/logs.

Android

Current candidate: 1.1.3, version code 5. Use its matching signed APK and manifest.

  1. Install the APK over the existing MedOS app.
  2. Import the phone-data ZIP only when the current kit requires it.
  3. Keep the phone awake during a large import.

Do not uninstall or clear storage to update or repair sync.

Update existing MedOS

For desktop base 1.1.4 or 1.1.5: export progression, stop MedOS, then extract the update ZIP into the existing MedOS folder, creating MedOS Update.

  • Windows: open MedOS Update/APPLY UPDATE - WINDOWS.cmd.
  • Mac: open MedOS Update/APPLY UPDATE - MAC.command.
  • Linux, from the MedOS root:
python3 "MedOS Update/apply_update.py" --root . --kit "MedOS Update"

The updater backs up old application files and restores a complete matching build while preserving medical data, private .env, and progression. Keep the backup until sign-in, a used/marked question, and an article work.

Never bypass hashes or BUILD_ID checks. A mixed build needs the complete cumulative update; an old Setup ZIP or selected frontend chunks are not a coherent repair.

UpToDate works automatically

The recognized bundled encrypted content needs no manual .env edit. Explicit custom content-key overrides still take priority. The source has 22,376 readable articles and 30 verified empty records. Optional preparation validates its cache and preserves an existing cache on failure.

The download ZIP password, MedOS sign-in password, and content key are separate.
