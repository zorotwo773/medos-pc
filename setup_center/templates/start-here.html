MEDOS OFFLINE SETUP CENTER

Start MedOS Setup

Choose your device below. The installer works from this SSD, preserves existing MedOS data, and does not need a network connection.

Windows

  1. Double-click START HERE - WINDOWS.cmd.
  2. If Windows asks, confirm that you opened the file from your complete copied or extracted MedOS folder.
  3. Your browser opens a local page. Click Start MedOS.

Keep the black window open until the page says MedOS is ready. No medical data is copied.

Manual command from Command Prompt:

"tools\python\python.exe" -B -E -s -m setup_center serve --drive-root "."

Mac

  1. Double-click START HERE - MAC.zip to extract it.
  2. Open MedOS Setup. Keep this SSD connected while setup checks and copies files.
  3. If macOS blocks the first launch, Control-click the app, choose Open, then confirm Open.

macOS security approval cannot be automated. MedOS Setup does not ask you to disable Gatekeeper or change system security.

Android

  1. Open ANDROID - COPY TO PHONE on this SSD.
  2. Copy that complete folder to the phone with a USB cable.
  3. On the phone, open the included guide, verify the displayed checksum, then tap the MedOS APK.
  4. Android may ask permission to install apps from your Files app. Approve only for this install, then turn it off again.

Updating the app preserves its private app data. Never uninstall MedOS or choose “Clear storage” during an update.

Windows starts directly from this folder

The same Setup detects Windows, Apple Silicon, or Intel Mac and uses the matching bundled runtime.

  • Copy or fully extract the complete folder to its permanent location first.
  • Double-click START HERE - WINDOWS.cmd, then click Start MedOS. There is no second copy of medical data.
  • MedOS prepares small per-user state, creates one MedOS shortcut, starts the app, and verifies it.
  • Keep the complete folder in place. If it moves, run START HERE - WINDOWS.cmd again from the new location.

The primary setup is offline-first. The universal release includes Windows, Apple Silicon, and Intel Mac runtimes. A controlled repair uses only a trusted release source and never installs arbitrary global packages.

Repair this SSD

If a launcher is missing or a security product blocks it:

  1. Do not format, erase, or “clean” the SSD.
  2. Reconnect it directly to the computer, without a USB hub, and try the device instructions once more.
  3. On Windows, open Command Prompt in this SSD folder and run:
"tools\python\python.exe" -B -E -s -m setup_center verify --drive-root "."

Save the exact final message. If verification reports a missing or changed file, use a trusted MedOS release source to refresh this SSD. Do not download individual runtime files from search results.

Security prompts and privacy

  • Modern Windows, macOS, and Android devices do not allow an SSD to install software automatically. One clear user approval is expected.
  • Setup installs per user by default and never installs system Python, Node, Homebrew, winget, or global packages.
  • Existing patient data, imported content, settings, and secrets are preserved.
  • Diagnostic bundles exclude environment files, databases, and full logs; known secrets and home-folder names are redacted.
